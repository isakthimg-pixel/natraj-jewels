NATRAJ JEWELS WEBSITE - HOW TO PUT IT ONLINE
============================================

What's in this folder
  index.html   the web page
  img/         all photos, the logo and the Instagram reel covers
Upload BOTH (keep the img folder next to index.html).

1. Upload
   Give this whole folder to whoever manages natrajjewels.com
   (or upload it yourself through your hosting's File Manager / FTP).
   index.html replaces the current home page, so keep a backup
   of the old site first.

2. Turn on enquiry emails (one time only)
   - Open the live site and send one test enquiry from the form.
   - FormSubmit will email natrajjewelsofficial@gmail.com with the
     subject "Action Required: Activate FormSubmit". Click the
     activation link in that email (check Spam if you don't see it).
   - Send a second test enquiry. It should now arrive in the inbox.
   From then on every enquiry is emailed to you automatically.
   If sending ever fails, customers see a "Send by email instead"
   button that opens their own email app with the enquiry filled in.

3. Things to update from time to time
   - Instagram reels: covers are in img/reels. Ask Claude to refresh
     them when you post new reels.
   - Google reviews: the five quotes are fixed text in index.html.
